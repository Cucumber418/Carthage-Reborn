# 历史地名对照表（审核稿）

迦太基征服某地区后，该地区改用下表中的名称。

## 取名原则

1. **优先用布匿语原名**：迦太基人自己建立或长期控制的地方，有史料记载布匿名的，用布匿名（如加迪尔、伊博西姆、齐兹）。
2. **其次用古典时代的通行名**：迦太基人没有留下自己叫法的地方，用布匿战争时代地中海世界通行的希腊或拉丁古名（如马萨利亚、伊特鲁里亚、赫尔维蒂亚）。
3. **中文译名用通行译法**：已有固定中文译名的（新迦太基、努米底亚、叙拉古、山南高卢等）沿用，不另起新译名。
4. **只改地区名**：城市名暂时保持原版，如果需要也可以一并改，单独列表。

> "原版地区"一栏是按原版中文地区名填写的暂定对照，具体的地区 key 拿到 1.15 本体文件后再逐个核对。如果原版的地区划分和下表不一致，会按实际划分调整。

## 需要你审核的地方

- 有没有你想换的名字，或者想按别的原则取名（比如统一用布匿语，或统一用拉丁语）。
- "西西里东部"直接叫"叙拉古"是否合适：好处是和日志条目呼应，缺点是把整个地区叫成一座城。
- 被征服地区的城市名要不要也一起改。
- 你文档里写的"泰尔"，表里改用了"推罗"：中文通行译名是推罗（如"推罗紫"），按制作规范统一用通行译名。如果你更想用泰尔也可以改回来。
- 原版"毛里塔尼亚"地区和古典时代的"毛里塔尼亚"（指摩洛哥）同名但不是一个地方，表里把原版毛里塔尼亚改称"利比腓尼基"，避免混淆。
