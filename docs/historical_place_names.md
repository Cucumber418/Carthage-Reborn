# 历史地名对照表

迦太基（主流文化为布匿的国家）拥有某个地区时，该地区改用下表中的名称；地区易手后恢复原名。开局时首都突尼斯即改称"迦太基"。

与原版一致：开启"无动态地名"游戏规则时不改名。

## 取名原则

1. **优先用布匿语原名**：迦太基人自己建立或长期控制的地方，有史料记载布匿名的，用布匿名（如加迪尔、伊博西姆、马莱特）。
2. **其次用古典时代的通行名**：迦太基人没有留下自己叫法的地方，用布匿战争时代地中海世界通行的希腊或拉丁古名（如马萨利亚、伊特鲁里亚、赫尔维蒂亚）。
3. **中文译名用通行译法**：已有固定中文译名的沿用，不另起新译名。
4. **只改地区名**：城市名暂时保持原版。

> 原版的西西里是一整个地区，没法分成东西两半，统一叫"叙拉古"，与日志条目"再临：叙拉古"对应。直布罗陀在原版里不是单独的地区，所以没有单独改名。
