# 迦太基重生 Carthage Reborn

维多利亚 3 模组。1836 年，突尼斯被一个刚刚复兴的布匿民族国家取代：保守而好战的元老们暂时掌握权力，国际社会尚未承认这个国家。它要在汉诺派与巴卡派的斗争中决定自己的道路，复兴布匿文化，并可能重建汉尼拔时代的版图。

- 适用版本：1.15.*
- 当前语言：简体中文（英文版之后统一补上）
- 模组前缀：`crb_`（所有新增的 key 都以此开头，避免和本体及其他模组冲突）

---

## ⚠️ 制作规范（最高优先级）

**本模组的一切游戏内容，包括文案、术语、数值、美术，都必须与原版维多利亚 3 的风格保持一致。** 玩家在游戏里看到的任何东西，都不应该让人感觉"这是模组加的"。所有新内容在提交前都要对照原版文件检查。

### 文案与语言

- **术语**：一律使用原版简体中文的官方译名，例如"利益集团""日志""影响力""合法性""鼓动者""政治运动""小市民""国教"等。原版已有的概念不另起新译名。
- **文风**：事件、日志、决议的描述沿用原版的叙事口吻，偏书面、克制、带一点历史感，不用网络用语、现代口语和过于煽情的表达。
- **篇幅**：标题、描述、选项的长度与原版同类内容相当。事件选项保持原版的简短风格。
- **格式**：变量、颜色、图标、超链接概念等写法照搬原版（如 `$VALUE|+=$`、`#bold ... #!`、`@money!`、`[concept_xxx]`），不自创格式。
- **人名地名**：音译参照原版和通行的中文译名习惯；历史上已有固定译名的（如汉尼拔、哈米尔卡、汉诺）使用固定译名。
- **英文版**：同样参照原版英文的术语和文风。

### 美术

- **旗帜**：按原版纹章系统（`coat_of_arms`）制作，配色、比例、图案布局参照 1836 年前后各国旗帜和原版旗帜的风格。原版图案库中没有的纹章（塔尼特符号、日轮新月、棕榈树），自绘时与原版纹章的画风、线条粗细、着色方式保持一致。
- **图标**：利益集团、法律、日志、修正等图标沿用原版的图标风格和尺寸，优先直接复用原版图标。
- **事件插图**：优先使用原版已有的事件插图。

### 机制与数值

- 新法律、修正、日志的数值规模参照原版同类内容，避免明显过强或过弱。
- 新机制尽量借用原版已有的结构（如日志的进度条、事件的选项格式），让玩家不需要额外学习。

## 二、日志

### 日志 1：汉诺派与巴卡派

参考原版会议波兰的"白党和红党"日志的结构：两派各有一条力量进度，随利益集团的政治力量、法律和事件变化。这是前期主线：玩家先打下开局宣称的土地，凯旋之后两派之争爆发，大约 5 年内决出胜负。

- **触发条件**：拥有的黎波里塔尼亚或君士坦丁的任意土地（即打下开局宣称的任意一地）
- **结束条件**：其中一派完全获胜；或双方保持僵持（双方力量占比都在 30% 到 70% 之间）满 4 年

| | 汉诺派 | 巴卡派 |
| --- | --- | --- |
| 控制者 | 保守的元老 | 广大公民与军人 |
| 主张 | 维持现状，避免与外国交战，保障田主利益，维持塔尼特多神教的主导地位 | 真正复兴迦太基共和国，复兴公民大会，为自己争取投票权；必要时迎出民族的皇帝，恢复布匿战争前的版图 |
| 主要利益集团 | 田主、船主、奉神者 | 军队、小市民、乡村民众 |
| 支持的法律 | 寡头制（两名苏菲特、元老院、贵族寡头）、世袭官僚、贸易保护 | 财产投票（恢复公民大会的权力）、选举官僚、重商主义 |
| 力量增长来源 | 支持的法律生效、主要利益集团掌权、和平年份 | 支持的法律生效、主要利益集团掌权、战争胜利、军队规模扩大 |

**实现方式（初版）**

- 进度条从 0（汉诺派完全获胜）到 100（巴卡派完全获胜），日志开始时为 60（巴卡派刚刚打赢开局的战争，略占上风）
- 每月变化：
  - 巴卡派：凯旋的余威 +0.5（日志开始后 2 年内）、财产投票 +0.2、选举官僚制 +0.15、重商主义 +0.15、处于战争 +0.6、军队政治力量不低于 20% +0.2、有巴卡主义者或汉尼拔主义者领导的利益集团执政 +0.2、元首是巴卡主义者或汉尼拔主义者 +0.3
  - 汉诺派：寡头制 -0.15、世袭官僚制 -0.1、贸易保护 -0.1、有汉诺主义者领导的利益集团执政 -0.2、元首是汉诺主义者 -0.3
  - 两派支持者的政治力量之差 × 1（哪派支持者影响力大就偏向哪派）
  - 按开局状态估算，玩家什么都不做时大概率进入僵持，然后自己选边；积极推动巴卡派的话，大约 2 到 3 年获胜
- 两个按钮，各冷却 2 年：
  - 向元老院让步：进度 -10，军队、小市民、乡村民众认同度 -2，持续 2.5 年
  - 向公民大会让步：进度 +10，田主、船主、奉神者认同度 -2，持续 2.5 年

**随机事件**：日志进行中平均每 5 个月左右弹出一个，同一事件 5 年内只出现一次。每个事件两个选项，分别偏向巴卡派和汉诺派（小幅 ±5，明显 ±8），同时影响相关利益集团的认同度。

| 事件 | 偏向巴卡派的选项 | 偏向汉诺派的选项 |
| --- | --- | --- |
| 老兵的请愿 | 让老兵成为公民（巴卡派明显增强，军队 +3，田主 -2） | 发放赏金（汉诺派小幅增强，花一笔钱） |
| 元老院的宴会 | 婉言谢绝（巴卡派小幅增强，小市民 +2，田主 -2） | 赴宴（汉诺派明显增强，田主、船主 +2） |
| 广场上的演说 | 容忍演说（巴卡派小幅增强，小市民 +2） | 驱散人群（汉诺派小幅增强，小市民 -2，产生激进分子） |
| 船主的商路 | 陆军优先（巴卡派小幅增强，军队 +2，船主 -2） | 商路优先（汉诺派小幅增强，船主 +3，军队 -2） |
| 塔尼特的神谕 | 预示胜利（巴卡派小幅增强，军队 +2） | 告诫审慎（汉诺派小幅增强，奉神者 +3） |
| 拖欠的军饷 | 向显贵征税（巴卡派明显增强，军队 +3，田主 -3） | 让军队等待（汉诺派小幅增强，军队 -3，产生激进分子） |
| 谁是迦太基人？ | 开放公民身份（巴卡派小幅增强，小市民、乡村民众 +2） | 封闭公民身份（汉诺派小幅增强，田主 +2，乡村民众 -2） |
| "国王"的流言（巴卡派超过 60% 时） | 一笑置之（巴卡派明显增强，军队 +2，合法性 -5） | 追查源头（汉诺派小幅增强，军队 -2，合法性 +5） |

特殊机制：随着军事力量增强，巴卡派刷出**汉尼拔主义者鼓动者**（君主制倾向）的概率越来越高。巴卡派力量达到 50% 后才会出现；每年的概率 = 军队政治力量 × 100%，巴卡派超过 75% 时翻倍，战争中再 ×1.5，最高 50%；同一时间只会有一位。

**结局**

| 结局 | 效果 |
| --- | --- |
| 巴卡派获胜 | 触发日志"汉尼拔再临"；获得修正"公民大会复兴"，持续 10 年：合法性 +10，军队政治力量 +10%，军队、小市民认同度 +3，乡村民众认同度 +2 |
| 汉诺派获胜 | 触发日志"汉诺航海记"；获得修正"元老院的和平"，持续 10 年：合法性 +10，改善关系速度 +25%，田主、奉神者认同度 +3，船主认同度 +2 |
| 僵持 4 年 | 弹出事件，由玩家选择最终倒向哪一派，获得该派的胜利效果；被抛弃的一派认同度 -3 到 -4，持续 5 年，并产生激进分子 |

### 日志 2：迦太基文化复兴

- **触发条件**：开局触发
- **结束条件**：迦太基的主流文化不再是布匿
- **全部完成时**：获得大量威望，获得永久修正"布匿复兴"（布匿人口的文化同化速度提高、威望提高）

## 三、决议

### 皈依伊斯兰教

- **出现条件**：本国信仰伊斯兰教的人口超过 40%（逊尼派、什叶派、伊巴德派等所有教派合计）
