# 迦太基重生 Carthage Reborn

维多利亚 3 模组。1836 年，突尼斯被一个刚刚复兴的布匿民族国家取代：保守而好战的元老们暂时掌握权力，国际社会尚未承认这个国家。它要在汉诺派与巴卡派的斗争中决定自己的道路，复兴布匿文化，并可能重建汉尼拔时代的版图。

- 适用版本：1.15.*
- 当前语言：简体中文（英文版之后统一补上）
- 模组前缀：`crb_`（所有新增的 key 都以此开头，避免和本体及其他模组冲突）

---

## ⚠️ 制作规范（最高优先级）

**本模组的一切游戏内容，包括文案、术语、数值、美术，都必须与原版维多利亚 3 的风格保持一致。** 玩家在游戏里看到的任何东西，都不应该让人感觉"这是模组加的"。所有新内容在提交前都要对照原版文件检查。

### 文案与语言

- **术语**：一律使用原版简体中文的官方译名，例如"利益集团""日志""影响力""合法性""鼓动者""政治运动""小市民""国教"等。原版已有的概念不另起新译名。
- **文风**：事件、日志、决议的描述沿用原版的叙事口吻，偏书面、克制、带一点历史感，不用网络用语、现代口语和过于煽情的表达。
- **篇幅**：标题、描述、选项的长度与原版同类内容相当。事件选项保持原版的简短风格。
- **格式**：变量、颜色、图标、超链接概念等写法照搬原版（如 `$VALUE|+=$`、`#bold ... #!`、`@money!`、`[concept_xxx]`），不自创格式。
- **人名地名**：音译参照原版和通行的中文译名习惯；历史上已有固定译名的（如汉尼拔、哈米尔卡、汉诺）使用固定译名。
- **英文版**：同样参照原版英文的术语和文风。

### 美术

- **旗帜**：按原版纹章系统（`coat_of_arms`）制作，配色、比例、图案布局参照 1836 年前后各国旗帜和原版旗帜的风格。原版图案库中没有的纹章（塔尼特符号、日轮新月、棕榈树），自绘时与原版纹章的画风、线条粗细、着色方式保持一致。
- **图标**：利益集团、法律、日志、修正等图标沿用原版的图标风格和尺寸，优先直接复用原版图标。
- **事件插图**：优先使用原版已有的事件插图。

### 机制与数值

- 新法律、修正、日志的数值规模参照原版同类内容，避免明显过强或过弱。
- 新机制尽量借用原版已有的结构（如日志的进度条、事件的选项格式），让玩家不需要额外学习。

## 一、基本设定

### 国家

| 项目 | 设定 |
| --- | --- |
| 替换对象 | 本体突尼斯（TUN）整体换成布匿 |
| 开局状态 | 新建立的重生民族国家，由保守主战派元老暂时掌控，**未受认可** |
| 国名 | 未受认可时叫 **布匿**，受认可后叫 **迦太基** |
| 首都 | 迦太基（突尼斯地区） |
| 主流文化 | 布匿 |
| 国教 | 塔尼特多神教 |
| 核心领土 | 迦太基本土与西西里，征服后直接管辖，不建傀儡国 |

### 文化

| 项目 | 设定 |
| --- | --- |
| 文化 | 布匿（`crb_punic`） |
| 遗产（母文化组） | 腓尼基（`heritage_crb_phoenician`） |

### 开局人口

开局时，在布匿的领土上：

- 首都所在地区：60% 的人口转为布匿文化
- 其余地区：20% 的人口转为布匿文化
- 转为布匿文化的人口同时改信塔尼特多神教

### 开局法律

| 法律组 | 法律 |
| --- | --- |
| 政体 | 双执政官（新法律，制作中，暂用议会共和制） |

### 旗帜

共五种，按政体切换：独裁 / 寡头 / 选举 / 社会主义 / 无政府主义。设计草稿已出，按原版纹章系统制作。各商站傀儡国另有各自定制的旗帜。

### 特殊利益集团

利益集团机制与本体相同，只改名称（和描述）。

| 本体利益集团 | 布匿名称 | 条件 |
| --- | --- | --- |
| 地主 | 田主 Ba'al Hasadeh | 受认可后变回"地主" |

| 虔信者 | 奉神者 Votaries | 仅在塔尼特多神教为国教时 |

迦太基征服的所有土地，地名都改为迦太基人对这些土地的历史称呼（需另行整理地名对照表）。

### 通用规则

- 通过日志或决议释放出的国家（傀儡国、商站等），国教都改为塔尼特多神教。
- 各商站有各自的预设法律和定制国旗。

## 二、日志

### 日志 1：汉诺派与巴卡派

- **触发条件**：小市民的政治力量超过 10%
- **结束条件**：其中一派完全获胜；或双方保持僵持（双方力量占比都在 30% 到 70% 之间）满 10 年

| | 汉诺派 | 巴卡派 |
| --- | --- | --- |
| 控制者 | 保守的元老 | 广大公民与军人 |
| 主张 | 维持现状，避免与外国交战，保障田主利益，维持塔尼特多神教的主导地位 | 真正复兴迦太基共和国，复兴公民大会，为自己争取投票权；必要时迎出民族的皇帝，恢复布匿战争前的版图 |
| 主要利益集团 | 田主、船主、奉神者 | 军队、小市民、乡村民众 |
| 支持的法律 | 寡头制（两名苏菲特、元老院、贵族寡头）、世袭官僚、贸易保护 | 财产投票（恢复公民大会的权力）、选举官僚、重商主义 |

特殊机制：随着军事力量增强，巴卡派刷出**君主制倾向鼓动者**的概率越来越高。

### 日志 2：迦太基文化复兴

- **触发条件**：开局触发
- **结束条件**：迦太基的主流文化不再是布匿

| 条目 | 内容 |
| --- | --- |
| 复兴种植园 | 在海内外拥有超过 20 家种植园 |
| 治理盐碱地 | 两千年前的罗马人曾在我们的土地上撒盐，而今日的我们将救回这片土地。需要研究灌溉。每年花费一笔资金，满 10 年完成，首都迦太基增加 50 耕地 |
| 推广多神教 | 全国 80% 以上人口皈依塔尼特多神教 |

### 日志 3：汉尼拔再临

- **触发条件**：巴卡派获胜
- **结束条件**：全部完成
- **触发时**：获得下列各地区的宣称
- 各条目可以不按顺序完成；所有条目完成时，军队和小市民都会获得满意度

| 条目 | 完成条件 | 完成后的选择 |
| --- | --- | --- |
| 渗透：的黎波里 | 征服的黎波里塔尼亚与昔兰尼加 | ① 花费恶名，把利比亚被征服的地区组建为傀儡国"的黎波里"<br>② 维持稳定：获得威望和效忠派 |
| 征服：努米底亚 | 征服阿尔及利亚诸城邦 | ① 花费恶名，把北非被征服的地区组建为傀儡国"努米底亚"<br>② 维持稳定：获得威望和效忠派<br>两个选项都会获得对摩洛哥全境的宣称 |
| 再临：叙拉古 | 征服西西里 | ① 花费恶名，5 年内大幅加快叙拉古的整合速度<br>② 维持稳定：获得威望和效忠派 |
| 吞并：地中海诸岛 | 征服巴利阿里群岛、马耳他、克里特等岛屿 | |
| 复兴：新迦太基 | 征服西班牙 3 个地区 | ① 花费恶名，把西班牙被征服的地区组建为傀儡国"伊比利亚商站"<br>② 维持稳定：获得威望和效忠派 |

迦太基本土和西西里是核心领土，不组建傀儡国，直接管辖。

### 日志 4：第 N 次布匿战争

- **触发条件**：与持有西西里任一地区的国家交战
- **完成条件**：迦太基控制西西里
- **名称**：首次触发叫"第三次布匿战争"；战争失败后再次触发时依次变为第四次、第五次……
- **进行中**：可选择提高战争支持度、降低厌战度
- **完成时**：
  - ① 获得威望
  - ② 获得一些恶名，同时获得对科西嘉、撒丁岛的宣称

### 日志 5：两千年的复仇路

- **触发条件**：完成"汉尼拔再临"中的"复兴：新迦太基"
- **完成条件**：拿下罗马并结束战争，弹出"复仇完成！"，获得大量威望和效忠派
- 通过四个按顺序解锁的决议推进：

| 阶段 | 决议 | 解锁条件 | 选择 |
| --- | --- | --- | --- |
| 1 | 翻过比利牛斯！ | 日志触发时可用 | ① 花费恶名，获得西班牙地中海沿岸全部地区的宣称<br>② 不要宣称，获得效忠派 |
| 2 | 越过高卢！ | 拿下第 1 阶段宣称的全部地区 | ① 花费恶名，获得汉尼拔行军经过的法国各地区的宣称<br>② 不要宣称，获得效忠派 |
| 3 | 翻过阿尔卑斯！ | 拿下第 2 阶段宣称的全部地区 | ① 花费恶名，获得瑞士全境和意大利北部阿尔卑斯沿线各地区的宣称<br>② 不要宣称，获得效忠派 |
| 4 | 复仇开始！ | 拿下第 3 阶段宣称的全部地区 | ① 花费恶名，获得意大利全境的宣称<br>② 不要宣称，获得效忠派 |

每完成一个阶段，第 2、3、4 阶段的决议会依次变成对应的处置决议（每完成一个阶段解锁一个）：

| 决议 | 效果 |
| --- | --- |
| 建立高卢商站 | 把在法国拿下的地区组建为傀儡国"高卢商站" |
| 建立雪山商站 | 把在瑞士、意大利北部拿下的地区组建为傀儡国"雪山商站" |
| 处置罗马 | ① 把在南意大利拿下的地区组建为"伊奥尼亚商站"<br>② 以牙还牙：在南意大利组建"罗马行省"共主邦联，彻底掌控罗马 |

## 三、决议

### 皈依伊斯兰教

- **出现条件**：本国信仰伊斯兰教（任一派别）的人口超过 40%；默认不显示，满足条件后出现在决议面板
- **失效条件**：国教已变为伊斯兰教的某一派别，或本国伊斯兰教人口降到 40% 以下（之后满足条件可再次出现）
- **描述**：为了在这片土地上存活，我们的执政官们只好带头改信周边的宗教……
- **效果**：参考国家集团"宗教大会"的强制皈依，对本国使用

### 扩张商站

- **解锁条件**：建立"新迦太基"之后
- **使用条件**：某个商站附近有新征服的土地，且本国不处于战争中
- **效果**：把迦太基在该地的地区转让给对应的商站（类似原版的扩张殖民地）

## 五、安装测试

1. 安装 [GitHub Desktop](https://desktop.github.com/)，登录自己的账号。
2. File → Clone repository，选择本仓库，本地路径选：
   `文档\Paradox Interactive\Victoria 3\mod\`
3. 打开游戏启动器 → Mods，把"迦太基重生"加入播放列表。
4. Steam 启动选项加上 `-debug_mode`，方便查看报错。
5. 以后有更新时，在 GitHub Desktop 点 **Fetch origin → Pull origin** 即可。

报错日志位置：`文档\Paradox Interactive\Victoria 3\logs\error.log`
