# 迦太基重生 Carthage Reborn

维多利亚 3 模组。1836 年，突尼斯被一个刚刚复兴的布匿民族国家取代：保守而好战的元老们暂时掌握权力，国际社会尚未承认这个国家。它要在汉诺派与巴卡派的斗争中决定自己的道路，复兴布匿文化，并可能重建汉尼拔时代的版图。

- 适用版本：1.15.*
- 当前语言：简体中文（英文版之后统一补上）
- 模组前缀：`crb_`（所有新增的 key 都以此开头，避免和本体及其他模组冲突）

## 一、基本设定

### 国家

| 项目 | 设定 |
| --- | --- |
| 替换对象 | 本体突尼斯（TUN）整体换成布匿 |
| 开局状态 | 新建立的重生民族国家，由保守主战派元老暂时掌控，**未受认可** |
| 国名 | 未受认可时叫 **布匿**，受认可后叫 **迦太基** |
| 首都 | 迦太基（突尼斯地区） |
| 主流文化 | 布匿 |
| 国教 | 塔尼特多神教 |

### 文化

| 项目 | 设定 |
| --- | --- |
| 文化 | 布匿（`crb_punic`） |
| 遗产（母文化组） | 腓尼基（`heritage_crb_phoenician`） |
| 语言 | 布匿语（`language_crb_punic`），属迦南语组 |
| 宗教 | 塔尼特多神教（`crb_tanit`） |

### 开局人口

开局时，在布匿的领土上：

- 首都所在地区：60% 的人口转为布匿文化
- 其余地区：20% 的人口转为布匿文化
- 转为布匿文化的人口同时改信塔尼特多神教

### 开局法律

| 法律组 | 法律 |
| --- | --- |
| 政体 | 双执政官（新法律，制作中，暂用议会共和制） |
| 权力分配 | 寡头制 |
| 官僚 | 世袭官僚 |
| 贸易 | 贸易保护 |
| 宗教 | 国教 |
| 其他 | 沿用传统国家的默认开局 |

共五种，按政体切换：独裁 / 寡头 / 选举 / 社会主义 / 无政府主义。暂时使用占位旗帜，之后再设计。

### 特殊利益集团

利益集团机制与本体相同，只改名称（和描述）。

| 本体利益集团 | 布匿名称 | 条件 |

## 二、决议（日志）

### 决议 1：汉诺派 vs 巴卡派

- **触发条件**：小市民的政治力量超过 10%
- **结束条件**：其中一派完全获胜；或双方保持僵持（双方力量占比都在 30% 到 70% 之间）满 10 年

| | 汉诺派 | 巴卡派 |
| --- | --- | --- |
| 控制者 | 保守的元老 | 广大公民与军人 |
| 主张 | 维持现状，避免与外国交战，保障田主利益，维持塔尼特多神教的主导地位 | 真正复兴迦太基共和国，复兴公民大会，为自己争取投票权；必要时迎出民族的皇帝，恢复布匿战争前的版图 |
| 主要利益集团 | 田主、船主、奉神者 | 军队、小市民、乡村民众 |
| 支持的法律 | 寡头制（两名苏菲特、元老院、贵族寡头）、世袭官僚、贸易保护 | 财产投票（恢复公民大会的权力）、选举官僚、重商主义 |

特殊机制：随着军事力量增强，巴卡派刷出**君主制倾向鼓动者**的概率越来越高。

### 决议 2：迦太基文化复兴

- **触发条件**：开局触发
- **结束条件**：迦太基的主流文化不再是布匿

| 条目 | 内容 |
| --- | --- |
| 复兴种植园 | 在海内外拥有超过 20 家种植园 |
| 治理盐碱 | 两千年前的罗马人曾在我们的土地上撒盐，而今日的我们将救回这片土地。需要研究灌溉。每年花费一笔资金，满 10 年完成，首都迦太基增加 50 耕地 |

### 决议 3：汉尼拔再临

- **触发条件**：巴卡派获胜
- **结束条件**：全部完成
- 各条目可以不按顺序完成

| 条目 | 内容 |
| --- | --- |
| 渗透：的黎波里 | 征服的黎波里塔尼亚与昔兰尼加 |
| 征服：努米底亚 | 征服阿尔及利亚诸城邦；之后可以选择把这些地区整合成傀儡国"努米底亚" |
| 再临：伟大沃土 | 征服西西里西部 |
| 吞并：地中海诸岛 | 征服巴利阿里群岛、马耳他 |
| 复兴：新迦太基 | 征服西班牙；用 3 个地区可以成立傀儡国"新迦太基" |

## 三、文件结构

```
Carthage-Reborn/
├── .metadata/metadata.json                     模组信息（启动器读取）
├── common/
│   ├── country_definitions/                    国家定义（替换 TUN）

│   ├── discrimination_traits/                  遗产、语言特征
│   ├── religions/                              塔尼特多神教
│   ├── static_modifiers/                       文化必需的修正
│   ├── history/countries/                      开局法律、国教
│   ├── history/characters/                     开局人物
│   ├── scripted_effects/                       复用的脚本效果（人口转换、利益集团改名）
│   └── on_actions/                             开局与每月检查
└── localization/simp_chinese/                  简体中文
    └── replace/                                覆盖本体文本（国名）
```

## 四、安装测试

1. 安装 [GitHub Desktop](https://desktop.github.com/)，登录自己的账号。
2. File → Clone repository，选择本仓库，本地路径选：
   `文档\Paradox Interactive\Victoria 3\mod\`
3. 打开游戏启动器 → Mods，把"迦太基重生"加入播放列表。
4. Steam 启动选项加上 `-debug_mode`，方便查看报错。
5. 以后有更新时，在 GitHub Desktop 点 **Fetch origin → Pull origin** 即可。

报错日志位置：`文档\Paradox Interactive\Victoria 3\logs\error.log`
